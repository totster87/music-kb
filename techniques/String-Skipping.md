# String Skipping

Jumping over one or more strings with the pick while maintaining clean tone — no accidental contact with the skipped string.

## The Problem
On all-downpicking, the wrist stays low after hitting a low string. The pick clips the middle string on the way to the target. At speed this compounds — each missed skip throws off timing and tone.

## The Fix
- Train the picking arc: wrist lifts slightly after the low string hit
- Rest pinky on the body as an anchor point for reference
- Isolate just the two-note skip (source + target) before adding context
- Slow enough that each landing is a decision, not a guess
