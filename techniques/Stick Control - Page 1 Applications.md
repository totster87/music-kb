# Stick Control — Page 1
*George Lawrence Stone*

User works heavily from page 1. Physical book — no patterns stored here.

## Applications

### 1. Hands (Standard)
Patterns as written, on snare/pad.

### 2. Feet
Patterns applied directly to feet (double bass / hi-hat foot).

### 3. Fill-In Application
When a pattern has consecutive same-hand strokes (e.g. R L R R), insert the opposite hand between the repeated notes (e.g. R L R R → R L R L R). Applied wherever the same hand repeats consecutively in the pattern.

### 4. Jazz Application
- R = bass drum foot
- L = hand
- Straight jazz ride pattern layered on top
- Hi-hat on 2 and 4

**Problem patterns:** pattern 9, 12, 13, and others with 3+ consecutive bass foot strokes — hi-hat placement on 2 and 4 gets disrupted and feels unbalanced. Two consecutive foot strokes is manageable; three or more breaks it down.

## Current BPM
- Jazz application (foot + hand + ride): 100 BPM actual
