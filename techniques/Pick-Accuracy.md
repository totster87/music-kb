# Pick Accuracy

Consistently landing the pick on the intended string, especially on descending runs at tempo.

## Current State
- Descending single-note runs: clips wrong string even at slow tempos
- This is a motion problem, not a speed problem
- Slowing down is not the fix — the motion itself is imprecise

## The Problem
On descending runs, the pick arc is inconsistent. The hand overshoots or undershoots the target string, landing on an adjacent string. Happens regardless of tempo — suggests the picking motion itself needs retraining, not just speed reduction.

## The Fix
- Identify the exact motion that causes the miss — watch the pick path
- Extreme slow motion: play the run at crawl tempo, making each pick a deliberate decision
- Stop the moment a note clips — don't push through
- Volume consistency is a diagnostic: uneven volume = uneven pick placement
