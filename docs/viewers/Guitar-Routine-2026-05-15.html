1 — Legato Warm-Up 5 min
Chromatic hammer-on / pull-off · String crossings
  • 1-2-3-4 chromatic hammer-ons across all 6 strings, ascending
  • Same descending with pull-offs
  • Focus: hammer-on volume should match the picked note — no fade
  • String crossings: the first hammer of each new string was uneven last time. Land that picked note hard so the hammers carry
Carry over: 2026-05-11 noted hammer-on inconsistency on the ascending string crossings. Slow enough that every hammer is heard.
2 — Upstroke Accent Drill 5 min
16th note alternate picking · Single string · Accent rotation
  • Pick one string (low E or A), 16th notes alternate picking
  • Cycle the accent: bar 1 = accent on 1, bar 2 = on the e, bar 3 = on the &, bar 4 = on the a
  • Each pass at 80 BPM, push to 100 BPM once even
  • Listen for the 2nd note (first upstroke) — that's where volume drops
Fix cue: Tremolo bursts go tense immediately. Stay relaxed — the upstroke should carry as much weight as the down, not less.

5 — Pinch Harmonic: B String Graduation 10 min
Technique · Drop C · Move from G string to B string
  • Tune to Drop C first
  • G string first (warm-up, 3 min): confirm the grip from last session — should hit ~80%+ clean now
  • B string (7 min): same grip, slightly more pick angle inward
  • One hit at a time — no chaining, no tempo, just landing the squeal
  • Target: hit rate over 50% on B string by end of block
Progression cue: Each string up requires a hair more thumb commitment. Last session locked G — today the goal is B feels as repeatable as G.
6 — ABR: Treatment 10 min
After the Burial · Section A · Drop C · Guitar 1 · Last max: 130 BPM · Target: 132
  • Open at 100 BPM — confirm pattern under fingers
  • Work toward 130 BPM, try 132 BPM if 130 is clean
  • Pinch harmonics: use the grip from block 5 — stop and reset on every miss
  • If the G string PHs are reliable and B string is starting to land, this block should hit cleaner than last time
Known issue: PH hit rate determines the speed ceiling, not the picking hand. Clean PH at 128 beats missed PHs at 133.
