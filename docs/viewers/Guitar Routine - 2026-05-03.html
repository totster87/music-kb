1 Drop D Spider Warm-Up 5 min
Warm-Up

Chromatic spider pattern across all six strings in Drop D. Start on the low D (string 6) and work chromatically up the neck — frets 5-6-7-8 per string, ascending then descending. Keep fingers arched, no muting of adjacent strings.

  • Start at 50–60 BPM, 16th notes. Raise only when clean.
  • Watch for tension in the fretting hand between strings 3 and 4.
  • Even pick attack across all strings — especially string 6 in Drop D.
  • One pass up + down = 1 rep. Do 3–4 reps before moving on.
2 String Skip Isolation Drill 10 min
Technique

Directly targets your known issue: clipping the wrong string mid-skip during all-downpicking. Pull the string-skipping moments from the Clean Intro and drill them in isolation, well below tempo.

  • Method: Pick note on string A, skip to string C, loop as a 2-note cell until automatic.
  • Start at 40–50 BPM. Completely controlled motion before raising speed.
  • All downstrokes — don't let the wrist rotate to compensate. Anchor stays fixed.
  • Slight upward tilt on the pick helps clear the middle string on the skip.
  • 5 min on the most awkward skip, then 5 min running the phrase with the fix embedded.
