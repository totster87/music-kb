Block 3 · 8 min — Subdivision Control
Morello — Table of Time
p.43 · ceiling: 53 BPM halftime · rushes on subdivision shifts
50–55 BPM halftime
  • Start at 50 BPM halftime — find the feel before pushing the ceiling.
  • The trap is anticipating the next subdivision before you're in it. Don't shift early — wait for it.
  • If you catch a rush: stop, reset, replay that one transition 4× in isolation, then re-enter the page.
  • Goal: push the ceiling to 55. Log the number you hold clean for 2+ minutes.
