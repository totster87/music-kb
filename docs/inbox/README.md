# Screenshot Inbox

Drop any drum/guitar transcription screenshots here, then tell Claude:

> "ingest inbox"

Claude will ask what each file is, move it to the right place, update the index, and commit.

## How to add from iPhone
1. Save screenshot to Files / Photos
2. Open GitHub app → navigate to `docs/inbox/`
3. Tap + → Upload file → pick your screenshot
4. Commit directly to main
5. Open Claude Code → say "ingest inbox"
